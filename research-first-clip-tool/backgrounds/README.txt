BACKGROUNDS FOLDER — framed shots ke peeche ye backgrounds lagenge.

Yahan apni background IMAGES (.jpg/.png) aur VIDEOS (.mp4/.mov/.webm) daalo.
Tool khud inhe rotate karke ~10-15 shots ke peeche (frame ke saath) lagayega —
har baar alag background + alag frame-style. Baaki poori video fullscreen.

- Ek folder me jitne chaho utne backgrounds rakho (images + videos dono).
- SUBFOLDERS bhi chalte hain: `backgrounds/Images/` aur `backgrounds/Videos/`
  (ya koi bhi naam) — tool andar tak dhoondh leta hai.
- Khali chhoda to tool "blur" background use karega (clip ka apna blurred version).
- Ye files repo/zip me commit NAHI hoti — sirf aapke computer par rehti hain.

Kitne framed shots aayenge, wo Style screen se set hota hai (default 12).
