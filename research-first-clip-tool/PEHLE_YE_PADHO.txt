=========================================================
  M4.2.1 — KYA KARNA HAI (8 step, seedhe shabdon mein)
=========================================================

Do folder hain. Inhe alag rakhna zaroori hai:

  A) NAYA FOLDER  = jo abhi aapne unzip kiya
     (isme naya code hai. Yahan kaam NAHI karna.)

  B) PURANA FOLDER = jisme aap ab tak kaam kar rahe the
     (isme aapka input\, jobs\, aur mehnat hai. Kaam YAHIN hoga.)

Purana folder DELETE mat karna. Replace bhi mat karna.


---------------------------------------------------------
STEP 1 — code update karo
---------------------------------------------------------
NAYE folder mein UPDATE_TOOL.bat par double-click karo.

Wo khud puchhega: "aapka chalta hua project folder kahan hai?"
PURANE folder ko uthakar us window mein DRAG kar do, Enter dabao,
phir "y" likho.

Ho gaya. Naya code purane folder mein lag gaya.
Aapka input\, DATA\ aur jobs\ ko haath nahi laga.

Aakhir mein wo khud check karke dikhayega:
    version, docs\ aaya ya nahi, aur aapka kaam surakshit hai ya nahi.

>> AB SE SAARA KAAM PURANE FOLDER MEIN HOGA. Naya folder chhod do.


---------------------------------------------------------
STEP 2 — khoya hua MEDIA wapas laao   (naya, M4.2.1)
---------------------------------------------------------
Pichhli baar ek bug ki wajah se aapke 16 DATA folder — jinme aapki
dhoondhi hui images/videos thi — DATA\_ORPHANED mein chale gaye the.

Ab tool wo khud wapas laa sakta hai. PURANE folder mein cmd kholo:

    node tools\recover-orphaned-media.js --dry-run

Ye sirf DIKHAYEGA ki kya kahan jayega. Kuch nahi badlega.
Theek lage to:

    node tools\recover-orphaned-media.js --apply

Zaroori baatein:
  - aapki koi maujooda file kabhi overwrite nahi hogi
  - _ORPHANED se kuch delete nahi hoga (copy hota hai)
  - jo match pakka nahi hai use tool khud nahi lagata — "[SHAYAD]"
    likh kar report mein daal deta hai, aap khud decide karo
  - poori report: output\orphan-recovery-report.json


---------------------------------------------------------
STEP 3 — khoya hua EVIDENCE wapas laao
---------------------------------------------------------
Ye tab hi karna jab aapke paas purana M3.6.1 wala folder abhi bhi ho.

    node tools\merge-pack.js input\scene-research.json "C:\...\researchfirstcliptoolM3.6.1\research-first-clip-tool\input\scene-research.json"

Ye sirf DIKHAYEGA. Kuch badlega nahi.

Kitna badhna chahiye? Iska koi FIX number nahi hai (pichhli baar maine
"68 hona chahiye" likh diya tha — wo galat tha). Ye ek UNION hai, aur
kitna badhega ye aapke abhi wale pack par depend karta hai.

Bas ye aakhri line dekho:

    [THEEK HAI] Kuch khoya nahi, aur N nayi validated cheezein aayi hain.

Aisa dikhe to wahi command dobara --apply laga kar chalao.
"[RUKO] Kuch evidence GHAT gaya" dikhe to --apply MAT chalana, mujhe
output\pack-merge-report.json bhej dena.

Purana folder ab nahi hai? Ye step chhod do. Kuch tootega nahi.


---------------------------------------------------------
STEP 4 — pack check
---------------------------------------------------------
START_HERE.bat -> option 2

"5 check fail" jaisa message aana normal hai — ghabrana nahi.
Wo raw research pack ka score hai, final video ka nahi.


---------------------------------------------------------
STEP 5 — DRAFT banao   (ye sabse bada step hai)
---------------------------------------------------------
START_HERE.bat -> D

Ab ye poori video bana dega aur kabhi beech mein rukega nahi.
Jahan tool ko koi footage nahi mila, wahan laal card aayega:
"MISSING 001", "MISSING 002" ...

Ye draft.mp4 hai. Ise dekh lo — pata chal jayega kahan kya kami hai.

Ek nayi baat (M4.2.1): agar aapka voiceover aur SRT ki lambai mein
2 second se zyada ka farak hua, to tool YAHIN saaf-saaf ruk jayega
aur batayega ki kya theek karna hai. Pehle wo 30 second tak chup-chaap
kaat deta tha — yaani aapki narration ka hissa gayab ho sakta tha.


---------------------------------------------------------
STEP 6 — DATA folder kholo
---------------------------------------------------------
Purane folder mein ab ek folder hoga: DATA\

Andar aise folder milenge:
    DATA\MISSING_001__02m03s-02m24s__P03_M01\

Har folder mein:
    WHAT_IS_MISSING.txt   <- YEHI PEHLE PADHO
    media\                <- files yahan daalni hain

WHAT_IS_MISSING.txt mein likha hoga:
    - video mein kis waqt ki baat hai
    - wahan narration kya keh rahi hai
    - kya dikhna chahiye, kya nahi
    - Google/YouTube par kya search karo


---------------------------------------------------------
STEP 7 — apni images/videos daalo
---------------------------------------------------------
Search karke jo mile, use us folder ke media\ mein copy kar do.

Order set karna ho to naam ke aage number lagao:
    01_pehli.jpg
    02_doosri.mp4
    03_teesri.jpg

Kuch folder par likha hoga "YE BEAT ZAROORI HAI (HARD_EVIDENCE)".
Aise folder mein ek khaali file bhi banani hai:
    APPROVE_MEDIA.txt
(Right-click -> New -> Text Document -> naam badal do)

Ye isliye ki zaroori beat par tool aapse ek saaf HAAN maangta hai.

NAYA (M4.2.1): ab wo HAAN us waqt ke media se BANDH jati hai.
Baad mein aap us folder ki file badal do, order badal do ya naya
voiceover laga do — to tool khud bolega:

    "manzoori expire ho gayi — media badal gaya, dobara dekh kar haan do"

Aur APPROVE_MEDIA.txt ka naam APPROVAL_EXPIRED.txt kar dega (andar wajah
likhi hogi). Ye jaan-boojh kar hai: purani haan naye visual par chipkani
nahi chahiye.

Dashboard chahiye to: START_UI.bat  (browser khul jayega, drag-drop
kar sakte ho, wahan approve ka tick bhi hai)
