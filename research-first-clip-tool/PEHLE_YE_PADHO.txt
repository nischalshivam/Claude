=========================================================
  M4.1 — KYA KARNA HAI (7 step, seedhe shabdon mein)
=========================================================

Do folder hain. Inhe alag rakhna zaroori hai:

  A) NAYA FOLDER  = jo abhi aapne unzip kiya
     (isme naya code hai. Yahan kaam NAHI karna.)

  B) PURANA FOLDER = jisme aap ab tak kaam kar rahe the
     (isme aapka input\, jobs\, aur mehnat hai. Kaam YAHIN hoga.)

Purana folder DELETE mat karna. Replace bhi mat karna.


---------------------------------------------------------
STEP 1 — code update karo
---------------------------------------------------------
NAYE folder mein UPDATE_TOOL.bat par double-click karo.

Wo khud puchhega: "aapka chalta hua project folder kahan hai?"
PURANE folder ko uthakar us window mein DRAG kar do, Enter dabao,
phir "y" likho.

Ho gaya. Naya code purane folder mein lag gaya.
Aapka input\, DATA\ aur jobs\ ko haath nahi laga.

>> AB SE SAARA KAAM PURANE FOLDER MEIN HOGA. Naya folder chhod do.


---------------------------------------------------------
STEP 2 — khoya hua evidence wapas laao
---------------------------------------------------------
Pichhli baar folder replace karne se aapke pack se 19 locators aur
19 frame hints kho gaye the. Wo wapas aane hain.

PURANE folder mein address bar par "cmd" likh kar Enter dabao
(ya Shift + right-click -> "Open PowerShell window here").

Phir ye paste karo:

    node tools\merge-pack.js input\scene-research.json reference-pack\M3.6.1-repaired-scene-research.json

Ye sirf DIKHAYEGA ki kya wapas aayega. Kuch badlega nahi.
"locators : 49 -> 68" jaisa dikhna chahiye.

Theek lage to wahi command dobara, aage --apply laga kar:

    node tools\merge-pack.js input\scene-research.json reference-pack\M3.6.1-repaired-scene-research.json --apply

Aapke theek kiye hue 31 cue aur 109 criticality waise ke waise rahenge.


---------------------------------------------------------
STEP 3 — pack check
---------------------------------------------------------
START_HERE.bat -> option 2

Coverage ~66% se badhkar ~78% ke aas-paas honi chahiye.
"5 check fail" jaisa message aana normal hai - ghabrana nahi.


---------------------------------------------------------
STEP 4 — DRAFT banao  (ye sabse bada step hai)
---------------------------------------------------------
START_HERE.bat -> D

Ab ye poori 15-minute video bana dega. Pehle ye timeline par ruk
jata tha - wo bug theek ho gaya.

Jahan tool ko koi footage nahi mila, wahan laal card aayega:
"MISSING 001", "MISSING 002" ...

Ye draft.mp4 hai. Ise dekh lo - pata chal jayega kahan kya kami hai.


---------------------------------------------------------
STEP 5 — DATA folder kholo
---------------------------------------------------------
Purane folder mein ab ek naya folder hoga: DATA\

Andar aise folder milenge:
    DATA\MISSING_001__02m03s-02m24s__P03_M01\

Har folder mein:
    WHAT_IS_MISSING.txt   <- YEHI PEHLE PADHO
    media\                <- files yahan daalni hain

WHAT_IS_MISSING.txt mein likha hoga:
    - video mein kis waqt ki baat hai
    - wahan narration kya keh rahi hai
    - kya dikhna chahiye, kya nahi
    - Google/YouTube par kya search karo


---------------------------------------------------------
STEP 6 — apni images/videos daalo
---------------------------------------------------------
Search karke jo mile, use us folder ke media\ mein copy kar do.

Order set karna ho to naam ke aage number lagao:
    01_pehli.jpg
    02_doosri.mp4
    03_teesri.jpg

Kuch folder par likha hoga "YE BEAT ZAROORI HAI (HARD_EVIDENCE)".
Aise folder mein ek khaali file bhi banani hai:
    APPROVE_MEDIA.txt
(Right-click -> New -> Text Document -> naam badal do)

Ye isliye ki zaroori beat par tool aapse ek saaf HAAN maangta hai.

Dashboard chahiye to: START_UI.bat  (browser khul jayega, drag-drop
kar sakte ho, wahan approve ka tick bhi hai)


---------------------------------------------------------
STEP 7 — final video
---------------------------------------------------------
START_HERE.bat -> option 8

Downloads dobara nahi honge - sirf naye hisse banenge.
final.mp4 mil jayegi. Uske saath shot-review.html kholna -
har shot ka frame ek page par dikhta hai.
