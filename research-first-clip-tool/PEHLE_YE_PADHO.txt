============================================================
  MOVIE EDITOR M5.0-B.2 — FRESH START, ONE-CLICK
============================================================

Purana folder drag, UPDATE_TOOL, ya files manually copy karna bilkul nahi.

1. ZIP ko ek nayi jagah unzip karo.
2. Sirf MOVIE_EDITOR.bat par double-click karo.
3. Browser mein New Video screen par ye files do:
   - Research pack (.json)
   - Voiceover (.mp3 / .m4a / .wav)
   - Clean script (.txt ya paste)
   - SRT: apni .srt do, ya Auto-banao dabao
4. Build -> Editor dabao. Build sach mein draft.mp4 banne ke baad hi Editor
   khulega. Failure hua to isi screen par exact reason aur log rahega.
5. Missing Media mein gaps bharo, Editor mein preview/edit karo, phir Export.

NOTE:
Purane research pack mein criticality missing ho to tool uski backup banakar
safe values khud bharega aur pack check dobara chalayega. Aapko REPAIR.bat ya
alag migration command chalane ki zaroorat nahi.

AGLI VIDEO:
UI ke andar Fresh start dabao. Purana project archive/ mein safe chala jayega;
input screen khali ho jayegi. Folder badalne ki zaroorat nahi.

AGAR DOBARA MOVIE_EDITOR CLICK KIYA:
Tool running instance ko hi dobara kholega. "address already in use" error
nahi aayega. Port busy ho to tool khud doosra free port chunega.

SUPPORT:
Build fail ho to New Video -> Progress ka poora text bhejo.
Launcher fail ho to .runtime/server-7900.log bhejo.
