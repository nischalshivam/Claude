---------------------------------------------------------
PEHLI BAAR — 2 STEP
---------------------------------------------------------
1. Is ZIP ko kahin bhi unzip karo (Desktop par nayi jagah — purane folders
   ko haath mat lagao, unki zaroorat nahi).

2. Andar START_UI.bat par double-click karo.
   Browser apne aap khul jayega: Movie Editor.

   (Node install hona chahiye — Node 18+. Agar "Node nahi mila" aaye to
    ek baar nodejs.org se install karke dobara chalao.)


---------------------------------------------------------
NAYI VIDEO BANANA — 4 CHEEZEIN, SAB UI SE
---------------------------------------------------------
Left mein "New Video" par jao. Teen cheezein deni hain:

  1) RESEARCH PACK (.json)
     Ye Genspark se banta hai. Nahi hai? Upar "Research pack chahiye?"
     button dabao — poora prompt milega. Use Genspark mein paste karo,
     apni script do, jo .json aaye use yahan daal do (drag ya click).
     Daalte hi tool bata dega: kitne packs, kitne moments — sahi hai ya nahi.

  2) VOICEOVER (mp3 / m4a / wav — koi bhi)
     Apni narration ki audio daalo. Tool khud samajh lega format.
     Daalte hi uski lambai dikh jayegi.

  3) CLEAN SCRIPT (narration ka text)
     Poori narration text box mein paste karo → "Script save karo".
     (ya .txt file daal do)

  Ab TIMING (.srt):
     - Aapke paas asli .srt hai (TTS/Whisper se)? "Apni .srt daalo" — sabse
       badhiya, exact timing.
     - Nahi hai? "Auto-banao (script + audio se)" dabao. Tool anumaan-timing
       ki .srt bana dega. Draft ke liye kaafi; editor mein theek kar sakte ho.

Sab hara (✓) dikhne lage to upar "Build → Editor" dabao.
Tool pehle pack check karega, phir poori draft video banayega. Progress
neeche live dikhega.


---------------------------------------------------------
DRAFT KE BAAD
---------------------------------------------------------
- "Editor" tab: har shot, preview, aur neeche timeline. Kisi shot par click
  karo — right side uski poori detail + trim/crop.

- "Missing Media" tab: jahan tool ko footage nahi mila (aksar wo movie jo
  internet par hai hi nahi), wahan apni image/video daalo — drag & drop.
  Zaroori (laal) beats par "approve" ka tick lagao.

- Sab bhar jaaye to "Export" (editor ke upar) — final video ban jayegi.
