# Video Automation Pipeline

Two tools that together turn a script into a ready-to-polish video:

1. **Footage Collector** (tool #1, separate project) — script/instructor file →
   scene-by-scene YouTube clips + images + frames (`output/scene_NNN/`).
2. **Auto Editor** (`auto_editor/`, this repo) — that footage + your narration
   audio → an editable **Wondershare Filmora project** (`.wfpbundle`) with
   clips arranged in sync with the narration, transitions, image animations
   and on-screen texts already applied.

Start here: `auto_editor/SETUP_GUIDE.md` (usage) and
`auto_editor/HANDOFF/` (full context for future changes, written for LLMs).
